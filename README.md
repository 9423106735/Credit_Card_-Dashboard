## Credit Card Dashboard

## Project Overview
This project presents an interactive credit card financial dashboard developed using Microsoft Power BI to analyze credit card transactions, customer behavior, and financial performance.
The dashboard helps stakeholders monitor credit card usage, revenue generation, transaction patterns, and customer spending behavior through dynamic visualizations and KPIs. Such dashboards are commonly used in financial analytics to track key metrics like revenue, interest earned, and transaction volumes.

##Tools & Technologies
- Microsoft Power BI – Dashboard creation
- SQL – Data extraction and transformation
- Excel / CSV files – Data storage and preprocessing
- DAX (Data Analysis Expressions) – KPI calculations

## Key Insights
- Certain card categories contribute significantly to revenue.
- Customer spending behavior varies across segments.
- Transaction trends reveal seasonal patterns in credit card usage.
- Some customer groups generate higher transaction volumes.

## Challenges Faced

During the development of the dashboard, several challenges were encountered:

1. Data Cleaning
Handling missing values and inconsistent formats required preprocessing before analysis.

2. Data Modeling
Creating relationships between customer and transaction datasets required proper data modeling in Power BI.

3. KPI Calculation
Developing accurate DAX measures for revenue, interest, and transaction metrics required careful validation.

4. Dashboard Design
Selecting the most effective charts and layouts to present financial insights clearly was challenging.
